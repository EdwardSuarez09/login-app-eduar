\# Login App - Eduar Suarez



Este es el proyecto integrador para el taller de Git y GitHub. Consiste en un formulario de inicio de sesión básico con validación de campos vacíos.



\## Estrategia de ramificación



Para este proyecto se eligió la estrategia \*\*GitHub Flow\*\*.



\### Justificación

\- La rama `main` siempre se mantiene estable y desplegable.

\- Las funcionalidades se desarrollan en ramas cortas (por ejemplo, `feature/formulario-login`).

\- Los cambios se integran a `main` únicamente mediante Pull Requests, lo que permite la revisión de código por parte de un compañero antes de fusionar.

\- Facilita la Integración Continua (CI), ya que los cambios se integran rápidamente y se ejecutan las verificaciones automatizadas (GitHub Actions) en cada PR.



\## Tecnologías utilizadas

\- HTML5

\- CSS3

\- JavaScript

\- Git y GitHub

\- GitHub Actions (Integración Continua)
